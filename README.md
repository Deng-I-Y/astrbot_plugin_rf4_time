# 俄罗斯钓鱼4时间与提醒（astrbot_plugin_rf4_time）

面板里显示的名字是「俄罗斯钓鱼4时间与提醒」，目录名和配置文件名仍是 `astrbot_plugin_rf4_time`，别改目录名，改了就丢配置。

《俄罗斯钓鱼4》游戏内时间换算 + 游戏时间提醒：游戏内 24 小时 = 现实 60 分钟。
即 1 游戏小时 = 现实 2.5 分钟，1 游戏分钟 = 现实 2.5 秒。

## 指令

| 指令 | 说明 |
| --- | --- |
| `/校时 08:00 14:30:41` | **只当偏差无法校正时使用**。**校准锚点 = 游戏时间 + 现实时间（精确到秒）**。用法：盯着游戏时钟，等它跳到 `08:00` 的那一瞬间，看现实时钟读到几秒（如 `14:30:41`），把两个时间一起发过来。游戏时间也认 `08：00` / `0800`。**只发游戏时间会有很大误差**，只写一个时间（`/校时 17:42`）时按收到消息那一刻当锚点。原始校时时间戳：游戏内时间 `20:29:00`，现实时间 `2026-10-29 16:51:13` |
| `/钓鱼时间` | 参考当前游戏内时间、离天亮(06:00)/天黑(21:00)还有多久；别名 `r4` / `rf4` / `游戏时间` |
| `/提醒 18:00 打窝` | 设一条游戏时间提醒，到点主动发消息；时间也可写 `1800`；别名 `打窝提醒` / `游戏提醒` / `rf4提醒` |
| `/提醒列表` | 看还挂着哪些提醒、各自还有多久；别名 `看提醒` / `rf4提醒列表` |
| `/取消提醒 2` | 取消编号 2 的提醒；别名 `删提醒` |
| `/补偿 5` | **游戏时间偏差补偿**：在算出来的游戏时间上加 5 分钟（`/补偿 -3` 往前拨、`/补偿 0` 清零、不写数字就是查当前值）；别名 `偏差补偿` / `时间补偿` / `rf4补偿`。会同步写回插件配置 `offset_minutes`，并重算已挂着的提醒 |

## 校准方法（锚点怎么定）

> **重要提醒：只当偏差无法校正时使用。**

校准锚点 = 游戏时间 + 现实时间（精确到秒），例如 `游戏 08:00 = 现实 14:30:41`。
用法：**盯着游戏时钟**。等它跳到 `08:00` 的那一瞬间，看现实时钟读到几秒（如 `14:30:41`），
把两个时间一起发过来：`/校时 08:00 14:30:41`。之后所有换算都从这条锚点按 2.5 秒/游戏分钟往后推，
误差只取决于你按发送的那一下手速。

**如果只发游戏时间会有很大误差**——没有现实时间，只能拿收到消息那一刻当锚点。

原始校时时间戳：游戏内时间 `20:29:00`，现实时间 `2026-10-29 16:51:13`
（对应 `anchor.json` 里 `anchor_real = 1793263873.0`、`anchor_game_min = 1229`）。

- 现实时间只写 `时:分` 也行，秒按 0 算
- 跨天校准（比如凌晨发的锚点其实是昨天晚上的时刻）会自动往前挪一天

## 配置项（AstrBot 插件配置里直接改，可交互）

| 配置 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `offset_minutes` | int | `0` | **游戏时间偏差补偿（分钟）**：在按锚点算出来的游戏时间上再加这么多分钟，正数往后推、负数往前拨，`0` 不补。用来修长时间挂机后慢慢攒出来的偏差 |

- 补偿只作用在「最终算出来的游戏时间」上，`/钓鱼时间`、`/提醒`、LLM 工具、后台提醒全部按补偿后的时间走
- `/钓鱼时间` 的输出里会多一行「已含偏差补偿 ±N 游戏分钟」，补偿为 0 时不显示
- 用 `/补偿 5` 改是立刻生效的，也会顺手同步进配置；直接改配置文件里的 `offset_minutes` 才要重载插件
- 锚点不用重新校，补偿和锚点是两回事

## 提醒怎么算（工作流）

1. 用户给的是**游戏内时间**，先按锚点换算成现实时间：
   `delta_game_min = (目标游戏分钟 - 当前游戏分钟) mod 1440`，为 0 时按等一整天处理；
   `触发现实时间 = 现在 + delta_game_min × 2.5 秒`。
2. 取「最近的一次」，即今天还没到就是今天，已经过了就是明天同一时刻。
3. 后台任务每 2 秒巡检一次 `reminders.json`，到点用 `context.send_message` 主动推给当时设提醒的会话（umo 已存）。
4. 发送失败最多试 3 次；错过超过 3 分钟不再补发（游戏里时间早过了，补发没意义）。
5. `/校时` 之后，所有未触发提醒会按新锚点重算现实时间，不会因为重新校准而错点。

## LLM 工具

- `rf4_game_time`：聊天里问「游戏里几点了」时由模型自行调用。
- `rf4_set_reminder(game_time, text)`：用户说「游戏时间 18:00 提醒我打窝」时由模型调用，等价于 `/提醒`。
- `rf4_set_offset(minutes)`：用户说「时间快了 3 分钟，往前拨一点」时由模型调用，等价于 `/补偿`。

## 存储

- 锚点：`data/plugin_data/astrbot_plugin_rf4_time/anchor.json`
- 提醒队列：`data/plugin_data/astrbot_plugin_rf4_time/reminders.json`

两者都是明文 JSON，重启不丢，可以直接手改。没校准过时按「现实今天 0 点 = 游戏 0 点」兜底，误差靠 `/校时` 修。

## 安装

在 AstrBot 面板「插件市场」搜「俄罗斯钓鱼4时间与提醒」安装，或者把整个目录放进 `data/plugins/`。
无第三方依赖，不需要装 requirements。
